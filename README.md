# Лабораторная работа 7: Структуры и файлы

## Автор
Горбунова Настя (Вариант 5)

## Цель работы
Научиться описывать запись объекта структурой `struct`, хранить коллекцию записей и обрабатывать её функциями. Читать и проверять данные текстового файла, выполнять запросы и сохранять одинаковый отчёт на экране и в файле.

## Задача
Файл содержит сведения о школьниках: фамилия, имя, рост и вес. 
Программа должна:
1. Вывести список школьников, рост которых превышает задаваемую величину.
2. Определить их средние показатели роста и веса.
3. Среди всех найти самого высокого школьника.

## Входные данные
1. Пользователь вводит с клавиатуры минимальный рост (целое число).
2. Программа читает файл `input.txt`, где каждая строка имеет вид: `Фамилия;Имя;Рост;Вес`. Поля разделены точкой с запятой.

## Выходные данные
1. Отчет выводится на экран.
2. Этот же отчет сохраняется в файл `output.txt`.
